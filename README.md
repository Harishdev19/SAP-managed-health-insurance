# 🏥 SAP Managed Health Insurance Claim System

A comprehensive **health insurance claim management system** built using **SAP ABAP** and **ABAP CDS Views**, designed to streamline the end-to-end process of submitting, tracking, and managing health insurance claims within an SAP environment.

## 📋 Overview

This project provides a structured and automated approach to managing health insurance claims for employees or policyholders. It leverages the power of SAP's ABAP stack and CDS (Core Data Services) to expose clean, analytical data models for claim processing, policy management, and approval workflows.

---

## 🚀 Features

- 📄 **Claim Submission** – Submit and register new health insurance claims
- 🔍 **Claim Tracking** – Monitor claim status from submission to settlement
- ✅ **Approval Workflow** – Multi-level claim approval and rejection handling
- 🏦 **Policy Management** – Link claims to employee insurance policies
- 📊 **CDS-Based Analytics** – Real-time reporting using ABAP CDS views
- 🔒 **Role-Based Access** – Controlled access for claimants, approvers, and admins

## ⚙️ Getting Started

### Prerequisites
- SAP NetWeaver or SAP S/4HANA system
- [abapGit](https://abapgit.org/) installed on your SAP system

### Installation

1. Open **abapGit** in your SAP system (transaction `ZABAPGIT`).
2. Click **"New Online"** and enter the repository URL:
3. 3. Select the target package and pull the objects.
4. Activate all imported objects.

---

## 📌 Use Case

Designed for organizations that manage employee health benefits within SAP, this system enables HR teams and insurance administrators to:
- Register and validate insurance claims digitally
- Track claim history per employee/policy
- Generate reports on claim settlements and pending approvals
